# AETHER - Ultra-Luxury Booking & Concierge Platform

An ultra-luxury, high-society multi-service booking platform for penthouses, villas, exotic supercars, private chauffeurs, Michelin-starred gastronomy, private yachts, and bespoke concierge services.

---

## 🌟 Key Features

- **Multi-Service Catalog**: Reserve verified penthouses, supercars, chauffeurs, and private jets across top global destinations (Paris, Côte d'Azur, Dubai, Lake Como, London, Tokyo, Aspen, etc.).
- **Live Multi-Currency Engine**: Instant conversion across `USD ($)`, `EUR (€)`, `GBP (£)`, `AED (د.إ)`, and `JPY (¥)`.
- **HUD Radar Map Integration**: Dynamic vector map with synced markers and interactive card highlight triggers.
- **Deep Product Details & Live Calculator**: Real-time pricing calculations, selectable VIP add-ons, and discount code validator (`AETHERVIP`, `SUMMER10`).
- **Payment Sandbox**: Simulated Stripe credit card checkout and Web3 / Crypto concierge escrow.
- **Multi-Role Dashboards**:
  - **Customer Portal**: Active reservations, voucher downloads, host communication, and cancellation.
  - **Partner Portal**: Earnings overview, active fleet/villa listings, reservation logs, and new asset listing creation.
  - **Admin Portal**: Platform KPIs, Partner KYC Verification Desk (1-click approve/reject), and asset audit tools.
- **Bespoke VIP Concierge Service**: Direct requests for jet charters, yacht buyouts, and diplomatic security escorts.
- **Persona Switcher**: Quick-testing tool to instantly switch roles between Guest, Customer, Approved Partner, Pending Partner, and Admin.

## 🚀 Getting Started

### 1. Direct Browser / Laragon
Open `index.html` directly in any modern web browser or serve it through your local web server (Laragon, Apache, Nginx):
```bash
# In your browser:
http://localhost/booking-platform/index.html
```

### 2. Full-Stack / Development Setup (Optional)
If running the TypeScript Vite frontend and Node backend:

#### Frontend:
```bash
cd frontend
npm install
npm run dev
```

#### Backend:
```bash
cd backend
npm install
npm run dev
```
