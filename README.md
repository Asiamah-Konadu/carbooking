# AETHER - Ghana's Premier Luxury Booking & Concierge Platform

An ultra-luxury, high-society multi-service booking platform tailored specifically for Ghana. Reserve 5-star presidential hotel suites, executive fleet rentals (**BMW xDrive**, **Mercedes-Benz GLE**, **Toyota Land Cruiser V8**, and **Toyota Vitz / Yaris**), security-vetted private chauffeurs, authentic Ghanaian fine dining, and bespoke diplomatic escort concierge services.

---

## 🌟 Key Features

- **Ghana Multi-Service Catalog**:
  - **5-Star Stays & Resorts**: Kempinski Hotel Gold Coast City Accra, The Royal Senchi Resort (Akosombo), Peduase Valley Resort (Aburi Hills), and luxury suites across Accra and Kumasi.
  - **Ghana's Most Wanted Fleet**:
    - **BMW X5 xDrive40i**: German engineering, intelligent AWD & M-Sport comfort.
    - **Mercedes-Benz GLE 450**: Executive status symbol with 4MATIC & Burmester surround sound.
    - **Toyota Land Cruiser V8**: Ghana's iconic heavyweight 4x4 for presidential presence and cross-country convoys.
    - **Toyota Vitz & Yaris**: Smart, fuel-efficient city cruisers with ice-cold air conditioning.
  - **Executive Chauffeurs**: Security-vetted VIP drivers with DVLA-cleared licenses.
  - **Authentic Ghanaian Gastronomy**: The Buka Restaurant (Osu), Skybar 25 Rooftop Lounge (Villaggio Vista), and private chefs in residence.
- **Excluded Non-Relevant Services**: Yachts & private jets have been completely excluded in accordance with the Ghana luxury travel ecosystem.
- **Ghanaian Hotel & Landscape Photography**: Hero section and destination cards showcase iconic Ghanaian locations (Accra, Kumasi, Takoradi, Aburi Hills, Akosombo & Lake Volta, Cape Coast).
- **Live Multi-Currency Engine**: Default **Ghanaian Cedi (`GHS - GH₵`)** with instant real-time conversion to `USD ($)`, `EUR (€)`, and `GBP (£)`.
- **HUD Radar Map Integration**: Dynamic vector map with synced markers across Greater Accra, Ashanti, and Western regions.
- **Deep Product Details & Live Calculator**: Real-time Ghanaian Cedi pricing calculations, selectable VIP add-ons, and promo code validators (`AETHERVIP`, `GHANA2026`).
- **Payment Sandbox**: Simulated Stripe credit card checkout and Mobile Money / Escrow protection.
- **Multi-Role Dashboards**:
  - **Customer Portal**: Active reservations, voucher downloads, host communication, and cancellation.
  - **Partner Portal**: Earnings overview, active Ghanaian fleet/suite listings, reservation logs, and new asset creation.
  - **Admin Portal**: Platform KPIs, Ghanaian Partner KYC Verification Desk (1-click approve/reject), and asset audit tools.
- **Bespoke VIP Concierge Service**: Direct requests for police escort motorcades, Land Cruiser V8 cross-country convoys, and VIP Kotoka International Airport (KIA) reception.
- **Persona Switcher**: Quick-testing tool to instantly switch roles between Guest, Customer, Approved Partner, Pending Partner, and Admin.

## 🚀 Getting Started & Deployment

### 1. Direct Browser / Laragon / Static Vercel Deployment
The root `index.html` (and `demo.html`) is a standalone, ultra-rich application with Firebase analytics and embedded Ghanaian luxury datasets:
```bash
# In your local browser:
http://localhost/booking-platform/index.html
# Or deploy root directly to Vercel (cleanUrls enabled)
```

### 2. Full-Stack / Development Setup (Optional)
If running the TypeScript Vite frontend and Node backend:

#### Frontend:
```bash
cd frontend
npm install
npm run dev
```

#### Backend:
```bash
cd backend
npm install
npm run dev
```
